A single 1024 × 1024 editorial poster summing up Thursday 26 November 2026:
the Thanksgiving storm in the US, the new tariffs, the warning of a fresh
Russian strike on Ukraine, the expanding Middle East conflict, an oil-facility
blast in Bangkok, and Ebola and a court ruling in Africa.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`make_image.py` is the development-time generator that drew `entry.png` with
Pillow; the entry program only copies the committed image.
